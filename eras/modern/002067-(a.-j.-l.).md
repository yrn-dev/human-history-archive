## Engineering and Structural Calculations
The archive includes technical data regarding the weight of main girders in bridge design. The weight of main girders ($W_g$) is calculated as $W_g = (W_l+W_f)k/(1-k)$, where $W_l+W_f$ is the known live load and dead load. 

Empirical relations provided by Waddell state that for weights of main girders per foot run ($w_1, w_2$) for a live load $p$ and spans $l_1, l_2$, the ratio is $w_2/w_1 = ½ [l_2/l_1+(l_2/l_1)^2]$. 

A formula from Unwin (1869) for the weight of main girders ($w_3$) is expressed as $w_3 = (w_1+w_2)l^2/(Cds-l_2) = (w_1+w_2)lr/(Cs-lr)$, where:
*   $w$ = total live load per ft. run of girder
*   $w_2$ = weight of platform per ft. run
*   $w_3$ = weight of main girders per ft. run (all in tons)
*   $l$ = span in ft.
*   $s$ = average stress in tons per sq. in. on gross section of metal
*   $d$ = depth of girder at centre in ft.
*   $r$ = ratio of span to depth ($l/d$)
*   $C$ = a constant for the girder type.
