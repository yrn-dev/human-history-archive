# I(u[theta])

In the context of calculating trajectories for high angle fire using Siacci's method, $I(u_{\theta})$ is a functional value used to determine the characteristics of a trajectory through successive arcs of small curvature.

## Calculation and Formulae
When applying Siacci's method, the curvature of an arc between the angles $\phi$ and $\theta$ is established. A first approximation for the value $\eta$ is given by the formula $\eta = 1/2(\phi + \theta)$. To determine $I(u_{\theta})$, a pseudo-velocity $u_{\phi}$ must first be calculated using the formula:

$u_{\phi} = v_{\phi} \cos \phi \sec \eta$

Once $u_{\phi}$ is known, and given the values for $\phi$ and $\theta$, $I(u_{\theta})$ is calculated according to the following formula:

(82) $I(u_{\theta}) = I(u_{\phi}) - \frac{\tan \phi - \tan \theta}{C \sec \eta}$

## Application in Trajectory Analysis
The value $I(u_{\theta})$ is part of a broader set of calculations used to find the coordinates and velocity of a projectile. It is utilized alongside $D(u_{\theta})$ and other functions such as $T$, $S$, and $A$. Specifically, the relationship between the coordinates $y$ and $x$ can be calculated via the following expression:

$\tan \phi - y/x = C \sec \eta [I(U) - \frac{A(U) - A(u)}{S(U) - S(u)}]$

Furthermore, the value $\phi(y/x)_{\theta}$ is expressed as:

(86) $\phi(y/x)_{\theta} = \tan \phi - C \sec \eta [I(u_{\phi}) - \Delta A / \Delta S]$

In this context, $\Delta$ represents any finite tabular difference of the function between the initial and final pseudo-velocity.
